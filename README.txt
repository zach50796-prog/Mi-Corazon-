MUSIC:
For the "Perfect" button to work, add your legally obtained copy of the song
to this folder and name it exactly:

perfect.mp3

The browser may block automatic music playback, so the site uses a button
after the letter is opened.

HOW TO PUT IT ONLINE:
1. Create a free GitHub account at https://github.com/
2. Create a new public repository, e.g. mi-corazon
3. Upload all files in this folder (including perfect.mp3 if you have it)
4. Open Settings > Pages
5. Under "Build and deployment", choose "Deploy from a branch"
6. Select the main branch and the root folder, then Save
7. GitHub will give you a public link you can send to your babe.

IMPORTANT:
Only upload music you have the right to use/share. If you do not have a
shareable copy of "Perfect", leave perfect.mp3 out and the rest of the
website will still work.
